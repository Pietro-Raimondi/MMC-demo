# MMC — Demo Underground

Prototipo dimostrativo con dati di esempio, senza backend e senza servizi IA collegati. I dati inseriti restano nella memoria del browser e si perdono ricaricando la pagina. Non inserire dati personali nella demo pubblica.

Questa copia contiene solo la demo e le risorse visive necessarie; il progetto di analisi MMC è separato. Immagini auto e garage generate; icone e branding MMC. Le fotografie esterne del prototipo locale sono sostituite da immagini generate e da un pneumatico SVG dimostrativo.

## Rimuovere la pubblicazione

Aprire Settings → Pages e disabilitare la pubblicazione impostando la sorgente su None. È anche possibile usare Unpublish site; nuovi deploy possono ripubblicarla. Il repository della demo può essere eliminato separatamente senza coinvolgere il progetto MMC.
